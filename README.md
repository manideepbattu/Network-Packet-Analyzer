
# Network Packet Analyzer

A beginner-level Python training assignment that demonstrates basic network packet capture and protocol identification using Scapy.

## Project Overview

This program captures network packets and displays basic information such as source IP address, destination IP address, and protocol type.

## Features

- Captures network packets using Scapy
- Identifies source and destination IP addresses
- Recognizes TCP, UDP, and ICMP protocols
- Supports optional packet filtering
- Displays basic packet information

## Technologies Used

- Python 3
- Scapy
- Networking fundamentals

## Requirements

- Python 3.x
- Scapy
- Appropriate permissions for packet capture
- Npcap on Windows, if required by your environment

Install Scapy:

```bash
pip install scapy
```

## How to Run

Clone the repository:

```bash
git clone https://github.com/manideepbattu/Network-Packet-Analyzer.git
```

Open the project folder:

```bash
cd Network-Packet-Analyzer
```

Run the program:

```bash
python Simple_Network_Packet_Analyser.py
```

## Learning Outcomes

- Basic packet capture concepts
- IP address identification
- TCP, UDP, and ICMP protocols
- Python programming with Scapy
- Introduction to network traffic analysis


## Security and Privacy Notice

Use this tool only on networks and devices you own or have explicit permission to monitor.

The program displays and logs source and destination IP addresses, which may be sensitive network metadata. Packet payload logging has been removed to reduce the risk of exposing private information.

This is an educational tool, not a production-grade network monitoring solution.
